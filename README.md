Student Management System
About the Project
The Student Management System is a web-based application developed using Java and Spring Boot to manage student information efficiently. It allows users to add, view, update, and delete student records through a user-friendly interface.

Features
Add new student records
View student details
Update student information
Delete student records
Store student data in a MySQL database
User-friendly and responsive web interface
Technologies Used
Backend: Java, Spring Boot
Frontend: HTML, CSS, Bootstrap, Thymeleaf
Database: MySQL
ORM: Spring Data JPA, Hibernate
Build Tool: Maven
Objectives
Simplify student record management.
Reduce manual paperwork.
Maintain student information efficiently.
Provide easy access to student records.
How to Run the Project
Clone the repository.
Open the project in an IDE such as IntelliJ IDEA or Eclipse.
Configure your MySQL database connection in application.properties.
Create the required database in MySQL.
Run the Spring Boot application.
Open the application in your browser using the configured local URL.
